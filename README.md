# Atelier de Estudo

Aplicação de estudo em português com flashcards, resumos, esquemas e planeamento.

Requer Node.js 22 ou superior.

```sh
npm ci
npm run check
npm run serve
```

O conteúdo incluído é uma demonstração de Geografia. O progresso fica no armazenamento local do navegador.

Esta versão pública omite referências pessoais, ligações privadas do Notion e configuração local de alojamento. O histórico público deve começar nesta versão para evitar divulgar dados das versões anteriores.
